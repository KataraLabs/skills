# Agent Skills by Addy Osmani

These copies are edited. They name no particular agent product or tool, and where a step needs
a shell, a commit, a separate reviewer or a browser, they say what to do if your agent can and
what to do if it cannot. The skills `spec`, `plan`, `build`, `test`, `review`, `ship`,
`simplify`, `a11y` and `webperf` are the project's command prompts rewritten as skills.
`references/` holds the shared checklists; each skill carries its own copy under
`references/shared/`.

Each SKILL.md names its upstream path in its front matter, and `sources.json` at the repository
root records the sha256 of every upstream file and of the edited copy.
